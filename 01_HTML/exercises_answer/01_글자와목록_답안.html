HTML 학습 정리

1일차 : 글자 관련 태그

오늘 배운 내용

HTML은 문서의 구조를 표현하는 마크업 언어이다. 태그의 의미에 맞게 쓰는 것이 중요하다.

태그는 모양이 아니라 의미로 고른다.

기억할 태그들

  • strong : 중요한 내용을 나타낸다.
  • em : 문장에서 강조할 부분을 나타낸다.
  • mark : 형광펜처럼 주목할 부분을 표시한다.

2일차 : 목록 관련 태그

학습 순서

  1. 태그의 종류와 의미를 익힌다.
  2. 문서의 구조를 먼저 잡는다.
  3. CSS로 스타일을 입힌다.

용어 정리

마크업
문서의 구조를 태그로 표시하는 것.
시맨틱
의미를 가진. 태그 이름만으로 역할을 알 수 있는 것.
