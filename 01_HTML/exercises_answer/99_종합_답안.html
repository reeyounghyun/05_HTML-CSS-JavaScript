소개

Java와 Spring으로 백엔드 개발을 해왔습니다. REST API 설계와 데이터베이스 모델링이 주된 작업이었고, 최근에는 AI 서비스 쪽으로 관심을 넓히고 있습니다.

서버만 만들다 보니 화면을 직접 다뤄본 경험이 적었습니다. 그래서 지금은 프론트엔드 기초부터 다시 쌓는 중입니다. 만드는 것보다 읽고 고칠 수 있는 것을 목표로 하고 있습니다.

기술 스택

Java / Spring Boot
주력 스택. REST API 설계와 JPA를 이용한 데이터 접근을 주로 다룹니다.
MySQL
스키마 설계와 쿼리 튜닝 경험이 있습니다.
Docker
개발 환경 구성과 배포에 사용합니다.
HTML / CSS / JavaScript
현재 학습 중입니다. React로 넘어가기 위한 기초를 다지고 있습니다.
